# 自动战斗

## 简介

按「战斗配置」中选择的方案自动战斗：位移、E、Q、切人、跳，开战时自动锁敌。战斗配置和战斗策略都是全局的，以后其他需要战斗的任务也会共用。

需要使用[color:red]**桌面端-前台**[/color]控制器，游戏分辨率为 16:9。

目前只支持**固定配队**：请先按方案说明在游戏里编好队伍，脚本不会识别或检查队伍。

## 使用步骤

1. 在游戏里编好队伍，进入大世界。
2. 打开 MXU「设置 → 任务设置 → 战斗配置」，选择战斗方案和队伍人数；需要时在「战斗策略」里关掉不想用的动作。需要 MXU v2.3.0 及以上；旧版本会用默认的「全队轮转」，全部动作启用。
3. 勾选「实时辅助 → 自动战斗」并启动。
4. 靠近敌人，看到敌人血条后脚本开始战斗。

## 任务选项

### 运行模式

- **单次**：等待进入战斗，打完一场后结束任务。等待超过「等待进战时间」仍未看到敌人时，任务结束。
- **持续**：一直监听，每次看到敌人就开打，直到手动停止。

### 单场最长时长

单场战斗超过该时长后结束，默认 300 秒，0 为不限制。

## 战斗配置

### 内置方案

每位角色进场都会先按 R（弧盘），再放 Q、E。

| 方案 | 适用 | 行为 |
|---|---|---|
| 全队轮转（默认） | 1~4 人任意队伍 | 每人 R → Q → E → 普攻 1.5 秒，按 1→2→3→4 切人 |
| 快速切人 | 技能冷却短、靠切人打反应的队伍 | 每人只放 R → Q → E 就切下一位（在场不足 1 秒用普攻补足） |
| 主C站场 | 1 号位放主C | 主C长时间站场输出，其余角色上场放技能后切回 1 号位 |
| 辅助先手 | 1 号位主C，2~4 号位辅助 | 2→3→4 依次挂增益，最后 1 号位主C长段爆发 |
| 双主C | 1、2 号位输出，3、4 号位辅助 | 3 → 1 → 4 → 2 循环，主C长段、辅助短段 |
| 重击流 | 重击收益高的角色 | 技能后轻击 0.4 秒接蓄力重击 1 秒，重复两次后切人 |
| 闪避游击 | 敌人攻击密集、队伍较脆 | 技能后「普攻 0.6 秒 → 闪避」重复三次后切人 |
| 单人循环 | 不想切人 | 当前角色反复 R → Q → E → 普攻 |
| 仅普攻 | 兜底 | 不切人、不放技能 |

技能冷却中按下 E/Q/R 不会生效，也不会影响后续操作。空槽位或阵亡角色在切人失败后会被本场跳过。

### 队伍人数

超出人数的槽位不会切过去，省掉空位的切人等待（每个约 1.2 秒）。方案的轮转会自动缩短，例如「主C站场」在 2 人队时变成 1 号、2 号交替。不确定时保持 4 人。

### 自定义方案（导入脚本）

1. 复制安装目录下的 `resource/base/combat/examples/custom_example.json` 到 `config/combat/`，改名并编辑。
2. 在「战斗配置」选择「自定义方案」，在「自定义方案文件」中填写文件名（如 `my_team.json`），也可以填写完整路径。
3. 启动任务。方案有错误时，日志会提示具体是哪个出招表、第几行第几列。

方案文件格式：

```jsonc
{
    "version": 1,
    "name": "我的方案",
    "team": [{"slot": 1, "character": "零", "note": "主C"}],   // 仅用于开战前提示编队
    "combos": {
        "1": ["ultimate, skill", "l_click(2)"],   // 1 号位的出招表，可写多行
        "default": "skill, l_click(1)"             // 其他槽位通用
    },
    "rotation": {"mode": "cycle", "order": [1, 2, 3, 4], "min_field_time": 1.0}
}
```

- `rotation.mode`：`cycle` 按 `order` 轮流切人；`stay` 不切人，反复执行当前角色的出招表（手动切人后会跟随）。
- `rotation.order`：轮转顺序，可重复，如 `[1, 2, 1, 3]`。
- `rotation.min_field_time`：每位角色最短在场秒数，不足时用普攻补足。
- 每个用到的槽位都要有出招表，或者提供 `default`。

### 出招表指令

逗号分隔的指令按顺序执行，每行可以写多条，`#` 后面是注释。语法与 ok-NTE 的出招表兼容。

| 指令 | 说明 |
|---|---|
| `skill` / `skill(0.5)` | E；带参数为长按秒数 |
| `ultimate` | Q；之后的指令会等终结技动画结束再执行 |
| `arc` | R（弧盘） |
| `l_click` / `l_click(2)` | 普攻一次 / 连续普攻 2 秒（别名 `attack`） |
| `r_click` / `r_click(1)` | 右键一次 / 连点 1 秒 |
| `l_hold(0.8)` / `r_hold(0.5)` | 按住左键（重击，别名 `heavy`）/ 右键，默认 0.6 / 0.3 秒 |
| `wait(0.5)` | 等待 |
| `jump` | 跳（空格） |
| `dodge` / `dodge(s)` | 闪避（左 Shift）；带方向时先按住方向键再闪避，如 `s` 后撤 |
| `sprint` / `sprint(0.5)` | 冲刺：按住 W 并点一下 Shift，默认 1 秒 |
| `walk(w, 0.3)` / `walk(wa, 0.3)` | 按住 w/a/s/d 移动指定秒数，可以斜向（不能同时写相反方向） |
| `lock` | 按鼠标中键锁敌 |
| `turn(90)` / `turn(-45)` | 向右 / 向左转动视角，-360~360 度（仅「桌面端-前台」控制器，角度受游戏灵敏度影响） |
| `switch(2)` | 切到 2 号位；切不过去时放弃本段剩余指令 |
| `keydown(a)` / `keyup(a)` / `keypress(a)` | 按下 / 松开 / 点按按键（字母、数字、space、shift、ctrl、alt、tab） |
| `mousedown(right)` / `mouseup(right)` / `click(middle)` | 鼠标按下 / 松开 / 点击（left、right、middle） |

限制：每段出招表最多 200 条指令，单条指令时长不超过 10 秒，方案文件不超过 64 KB。段末仍按住的键会自动松开。在「战斗策略」里关掉的动作，在自定义方案里同样会跳过。条件分支（`if`）、循环等写法暂不支持。

示例：

```text
lock, ultimate                # 锁敌后先放大招
sprint(0.6), jump, l_click(1) # 冲刺贴近、跳起普攻
walk(wa, 0.3), skill(0.3), dodge(s), heavy(0.8)
```

## 战斗策略

「设置 → 任务设置 → 战斗策略」对所有方案生效，包括自定义方案。

| 选项 | 默认 | 说明 |
|---|---|---|
| 不使用的动作 | 都不勾 | 勾选的终结技、技能、弧盘、闪避、跳跃、切人在出招时跳过；勾选切人后只用当前角色战斗 |
| 锁定目标 | 开 | 开战时按鼠标中键锁敌，看不到敌人血条时每 0.6 秒重新锁定 |
| 找不到敌人时转动视角 | 关 | 看不到敌人超过 1 秒时向右转动视角找敌人，最多转一圈 |
| 脱战确认时间 | 3 秒 | 敌人血条持续消失多久判定战斗结束，敌人经常跑出画面时调大 |

另外，看不到敌人超过 1 秒时会暂缓终结技，避免放空。

## 常见问题

- **一直提示等待敌人**：脚本通过敌人头顶的红色血条判断是否进入战斗，敌人不在画面内时识别不到，请靠近敌人。
- **提示某号位无法切换**：该槽位为空或角色已阵亡，本场战斗会跳过它。
- **提示识别不到当前角色**：右侧队伍栏被遮挡或分辨率不是 16:9，脚本会改为只用当前角色战斗。
- **战斗中途结束**：阵亡、进入剧情或弹窗导致长时间看不到战斗界面时，本场战斗会结束。
- **中键在游戏里是别的功能**：在「战斗策略」里关闭「锁定目标」。
- **转视角没反应**：只有「桌面端-前台」控制器支持转视角，其他控制器下会自动忽略。
- **只想用一个角色**：选「单人循环」，或者在「不使用的动作」里勾选「切人」。
