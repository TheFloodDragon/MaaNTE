# 自动战斗

## 简介

按「战斗配置」中选择的方案自动战斗：位移、E、Q、切人、跳，开战时自动锁敌。战斗配置和战斗策略都是全局的，以后其他需要战斗的任务也会共用。

需要使用[color:red]**桌面端-前台**[/color]控制器，游戏分辨率为 16:9。

目前只支持**固定配队**：请先按方案说明在游戏里编好队伍，脚本不会识别、检查或更换队伍。

## 使用步骤

1. 在游戏里编好队伍，进入大世界。
2. 打开 MXU「设置 → 任务设置 → 战斗配置」，选择战斗方案和队伍人数；需要时在「识别与安全策略」里关掉不想用的动作，在「角色与轮转」里调整首发、顺序或某个槽位的出招。需要 MXU v2.3.0 及以上；旧版本会用默认的「全队轮转」，全部动作启用。
3. 勾选「实时辅助 → 自动战斗」并启动。
4. 靠近敌人，连续两张截图看到敌人后脚本开始战斗。日志会先列出本场实际执行的方案、输入节奏、轮转和每个槽位的出招。

## 任务选项

### 运行模式

- **单次**：等待进入战斗，打完一场后结束任务。等待超过「等待进战时间」仍未看到敌人时，任务结束。
- **持续**：一直监听，每次看到敌人就开打。一场结束或目标丢失后回到监听；撤离、超时、长时间看不到界面、截图失败或出错时结束任务，不会在撤离后立刻重开。

### 单场最长时长

单场战斗超过该时长后结束，默认 300 秒，0 为不限制。达到时长记为「超时」，不算胜利。

### 结束结果

日志里的「本场结束：……」说明了停下的原因：

| 结果 | 含义 |
|---|---|
| 确认胜利 | 检测到明确的清场证据。普通大世界里通常没有胜利画面可识别，这时不会出现这个结果 |
| 目标丢失 | 连续一段时间确实看不到任何敌人，已停止输出。**不代表敌人已清空**，可能只是敌人跑出了画面 |
| 确认已脱离 / 确认已撤离 / 战斗失败 | 由其他任务提供的识别确认，自动战斗任务本身不会单独产生 |
| 超时 | 达到单场最长时长 |
| 长时间看不到战斗界面 | 阵亡、剧情、弹窗或撤离转场 |
| 长时间无法截图或识别 | 截图失败或识别持续出错，已停止输入 |

## 战斗配置

### 内置方案

每位角色进场都会先按 R（弧盘），再放 Q、E。轮转方案开战时会先切到「首发」角色。

| 方案 | 适用 | 轮转（首发） | 行为 |
|---|---|---|---|
| 全队轮转（默认） | 1~4 人任意队伍 | 1→2→3→4（1 号位） | 每人 R → Q → E → 普攻 1.5 秒 |
| 快速切人 | 技能冷却短、靠切人打反应的队伍 | 1→2→3→4（1 号位） | 每人只放 R → Q → E 就切下一位（在场不足 1 秒用普攻补足） |
| 主C站场 | 1 号位放主C | 1→2→1→3→1→4（1 号位） | 主C R → Q → E 后普攻 3 秒、E、普攻 2 秒；其余角色放技能后切回 1 号位 |
| 辅助先手 | 1 号位主C，2~4 号位辅助 | 2→3→4→1（2 号位） | 辅助依次挂增益，最后 1 号位主C长段爆发 |
| 双主C | 1、2 号位输出，3、4 号位辅助 | 3→1→4→2（3 号位） | 主C长段、辅助短段交替 |
| 重击流 | 重击收益高的角色 | 1→2→3→4（1 号位） | 技能后轻击 0.4 秒接蓄力重击 1 秒，重复两次后切人 |
| 闪避游击 | 敌人攻击密集、队伍较脆 | 1→2→3→4（1 号位） | 技能后「普攻 0.6 秒 → 闪避」重复三次后切人 |
| 单人循环 | 不想切人 | 不切人 | 当前角色反复 R → Q → E → 普攻 2 秒 |
| 仅普攻 | 兜底 | 不切人 | 不放技能 |

技能冷却中按下 E/Q/R 不会生效，也不会影响后续操作。空槽位或阵亡角色在切人失败后会被本场跳过。

### 队伍人数

超出人数的槽位不会切过去，省掉空位的切人等待（每个约 1.2 秒）。方案的轮转会自动缩短，例如「主C站场」在 2 人队时变成 1 号、2 号交替。不确定时保持 4 人。

## 角色与轮转

「设置 → 任务设置 → 角色与轮转」默认收起。打开「高级调整」后可以在不写方案文件的情况下改动所选方案；关闭后全部恢复为方案原样。留空的项目一律沿用方案。

| 选项 | 说明 |
|---|---|
| 轮转方式 | 沿用方案 / 轮转 / 站场 |
| 轮转顺序 | 逗号分隔的槽位号，第一个就是首发，可重复，如 `1,2,1,3` |
| 最短站场时间 | 所有角色上场后至少停留的秒数，出招提前结束时用普攻补足 |
| 不参与轮转的槽位 | 勾选的槽位不会被切入，也会从轮转顺序和出招表的 `switch(n)` 中去掉 |
| 1~4 号位 | 每个槽位的角色名称、备注、出招、站场时间。出招与方案文件语法相同，如 `skill, ultimate, l_click(1.5)` |

- 角色名称和备注只是你的标注，用于开战摘要和提示；脚本不识别头像，也不会去游戏里换队。
- 出招写错、轮转里没有可用槽位、数值越界时，开战前就会报错并停止，不会悄悄换成别的出招。
- 槽位里没有填出招时，沿用方案的出招；摘要中会标明每个槽位的出招来自方案、方案默认还是自定义。

### 输入节奏

「输入节奏倍率」调整脚本按键的疏密，**不是游戏速度**，也不影响技能冷却和动画。2.0 点得更密，0.5 点得更疏，1.0 与原来一致。蓄力、移动、等待、站场时长和切人确认仍按真实秒数执行。网络或电脑较卡、按键容易被吞时可以调低。

### 自定义方案（导入脚本）

1. 复制安装目录下的 `resource/base/combat/examples/custom_example.json` 到 `config/combat/`，改名并编辑。
2. 在「战斗配置」选择「自定义方案」，在「自定义方案文件」中填写文件名（如 `my_team.json`），也可以填写完整路径。
3. 启动任务。方案有错误时，日志会提示具体是哪个出招表、第几行第几列。

方案文件格式：

```jsonc
{
    "version": 1,
    "name": "我的方案",
    "team": [{"slot": 1, "character": "零", "note": "主C"}],   // 仅用于开战前提示编队
    "combos": {
        "1": ["ultimate, skill", "l_click(2)"],   // 1 号位的出招表，可写多行
        "default": "skill, l_click(1)"             // 其他槽位通用
    },
    "rotation": {"mode": "cycle", "order": [1, 2, 3, 4], "min_field_time": 1.0}
}
```

- `rotation.mode`：`cycle` 按 `order` 轮流切人；`stay` 不切人，反复执行当前角色的出招表（手动切人后会跟随）。
- `rotation.order`：轮转顺序，可重复，如 `[1, 2, 1, 3]`。
- `rotation.min_field_time`：每位角色最短在场秒数，不足时用普攻补足。
- 每个用到的槽位都要有出招表，或者提供 `default`。

### 出招表指令

逗号分隔的指令按顺序执行，每行可以写多条，`#` 后面是注释。语法与 ok-NTE 的出招表兼容。

| 指令 | 说明 |
|---|---|
| `skill` / `skill(0.5)` | E；带参数为长按秒数 |
| `ultimate` | Q；之后的指令会等终结技动画结束再执行 |
| `arc` | R（弧盘） |
| `l_click` / `l_click(2)` | 普攻一次 / 连续普攻 2 秒（别名 `attack`） |
| `r_click` / `r_click(1)` | 右键一次 / 连点 1 秒 |
| `l_hold(0.8)` / `r_hold(0.5)` | 按住左键（重击，别名 `heavy`）/ 右键，默认 0.6 / 0.3 秒 |
| `wait(0.5)` | 等待 |
| `jump` | 跳（空格） |
| `dodge` / `dodge(s)` | 闪避（左 Shift）；带方向时先按住方向键再闪避，如 `s` 后撤 |
| `sprint` / `sprint(0.5)` | 冲刺：按住 W 并点一下 Shift，默认 1 秒 |
| `walk(w, 0.3)` / `walk(wa, 0.3)` | 按住 w/a/s/d 移动指定秒数，可以斜向（不能同时写相反方向） |
| `lock` | 按鼠标中键锁敌 |
| `turn(90)` / `turn(-45)` | 向右 / 向左转动视角，-360~360 度（仅「桌面端-前台」控制器，角度受游戏灵敏度影响） |
| `switch(2)` | 切到 2 号位；切不过去时放弃本段剩余指令 |
| `speed(1.5)` | 把本场后续的输入节奏改为 1.5 倍（0.5~2.0），不按任何键 |
| `keydown(a)` / `keyup(a)` / `keypress(a)` | 按下 / 松开 / 点按按键（字母、数字、space、shift、ctrl、alt、tab） |
| `mousedown(right)` / `mouseup(right)` / `click(middle)` | 鼠标按下 / 松开 / 点击（left、right、middle） |

限制：每段出招表最多 200 条指令，单条指令时长不超过 10 秒，方案文件不超过 64 KB。段末仍按住的键会自动松开。在「识别与安全策略」里关掉的动作，在自定义方案里同样会跳过，用原始按键写的同一动作（如 `keypress(q)`）也会跳过。条件分支（`if`）、循环等写法暂不支持。

示例：

```text
lock, ultimate                # 锁敌后先放大招
sprint(0.6), jump, l_click(1) # 冲刺贴近、跳起普攻
walk(wa, 0.3), skill(0.3), dodge(s), heavy(0.8)
```

## 识别与安全策略

「设置 → 任务设置 → 识别与安全策略」对所有方案生效，包括自定义方案。

| 选项 | 默认 | 说明 |
|---|---|---|
| 不使用的动作 | 都不勾 | 勾选的终结技、技能、弧盘、闪避、跳跃、切人在出招时跳过；勾选切人后只用当前角色战斗 |
| 锁定目标 | 开 | 开战时按一次鼠标中键锁敌；每次丢失目标后最多重新锁定一次，不会反复按中键 |
| 找不到敌人时转动视角 | 关 | 看不到敌人超过 1 秒时向右转动视角找敌人，最多 4 次，每次转动后重新判断 |
| 辅助识别敌人 | 开 | 血条看不到时，再用血条形状、敌人等级、Boss 等级确认敌人还在，减少敌人被遮挡时提前停手 |
| 目标丢失等待时间 | 3 秒 | 连续多久确实看不到敌人后停止本场，敌人经常跑出画面时调大 |

另外：

- 看不到敌人超过 1 秒时会暂缓终结技，避免放空。
- 出现菜单、撤离确认、黑屏加载或识别失败时暂停所有输入，并松开按住的键；恢复后重新截图确认再继续，不会盲打。
- 看到「确认撤离」界面只会暂停，不会替你点确认；取消撤离并重新看到敌人后继续战斗。

## 常见问题

- **一直提示等待敌人**：脚本通过敌人头顶的红色血条或等级文字判断是否进入战斗，敌人不在画面内时识别不到，请靠近敌人。
- **战斗中途结束，结果是「目标丢失」**：敌人跑出画面或被遮挡太久。可以调大「目标丢失等待时间」，或打开「找不到敌人时转动视角」。
- **一直打到超时才结束**：画面里可能有被误认为敌人血条或等级的红色/文字元素。可以先关闭「辅助识别敌人」，只用血条颜色判断。
- **提示某号位无法切换**：该槽位为空或角色已阵亡，本场战斗会跳过它。
- **提示识别不到当前角色**：右侧队伍栏被遮挡或分辨率不是 16:9，脚本会改为只用当前角色战斗。
- **提示配置错误、没有开打**：检查「角色与轮转」中填写的出招和顺序，日志会写明是哪个槽位、第几列。
- **中键在游戏里是别的功能**：在「识别与安全策略」里关闭「锁定目标」。
- **转视角没反应**：只有「桌面端-前台」控制器支持转视角，其他控制器下会自动忽略。
- **只想用一个角色**：选「单人循环」，或者在「不使用的动作」里勾选「切人」。
- **想让某个角色不上场**：在「角色与轮转 → 不参与轮转的槽位」里勾选它。
